LSMA fractions vs spectral indices

fortnightly Sentinel-2 L2A, Jan 2023 - Sep 2026. Endmember fractions (fully constrained LSMA, endmembers extracted from these scenes) above; the NDVI / NDBI / SWIR means the current detector uses below. Both are computed from the same rasters and the same cloud mask, so the two feature spaces are directly comparable. A solid red rule marks a verified construction start; a grey dashed rule marks a pseudo-start — an anchor drawn on a campus that never started, used only to centre the same season-matched window.

Series AOI View

Gaps are real: a break in a line means no scene that fortnight passed the 40% cloud filter, not a value of zero - nothing is interpolated across them. Periods with under 45% valid pixels are drawn at reduced opacity because thin cloud unmixes as high albedo (that fraction anti-correlates with valid pixel count at -0.37 to -0.42), so spikes there are suspect. The paper's own noise filter for this is not yet implemented.
