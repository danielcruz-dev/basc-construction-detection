## 1. What was built

Pipeline: AOI → per-pixel Sentinel-2 fetch → SCL + s2cloudless mask → fully constrained
LSMA → seasonal-baseline change → connected components → zone features → 0–15% stage.

| module | does |
|---|---|
| `aoi.py` | unified resolver: site plan > parcel > point box, gated by observation date |
| `geo_utils.py` | metre-accurate buffering, AOI rasterisation, geodesic measures |
| `siteplan_meta.py` | document/revision/public dates, plan type, `usable_from`; strict vs relaxed |
| `tiling.py` | overlapping tiles, components merged across seams by union-find |
| `change.py` | per-pixel seasonal baseline (median/MAD **and** mean/sd), components, features |
| `detect.py` | causal states: `insufficient_evidence` / `provisional_start` / `confirmed_start` |
| `stage.py` | 0/5/10/15 with `stage_group="10-15"` abstention |
| `truth.py` | start as an INTERVAL; reported dates preserved separately |
| `basc_fetch/lsma/series/chips/features/test/build_viz` | the runnable pipeline + viewer |

Docs: `basc/MODEL_STRUCTURE.txt` (§11 revisions, §12 dataset requirements).

## 2. Findings that changed the design

**The AOI dominates everything.** 8,000 m² as a share of the AOI: Microsoft's 320 ha
parcel 0.25%, Digital's 181 ha 0.44%, a 400 m box 5.00%. The parcel mean cannot see a
construction pad. This is why the previous generation looked weak.

**The site point is not where the construction is.** Top-5% changed pixels, distance
from the confirmed coordinate:

    site           bld  median   within 400 m   within 1000 m
    NTT IL           3   144 m       98%            100%
    Eagan MN         1    98 m       95%            100%
    Digital VA      11   375 m       26%             71%
    Microsoft WI     9   554 m        0%             39%
    QTS IA           7   751 m        0%              0%

All five `coord_confirmed`. Only 362 of 1,209 coordinates are confirmed at all.

**Cloud is two problems, and only one is fixable by thresholds.** The tile-level
`maxCloudCoverage` filter is measured over the whole ~110 km granule: relaxing it 40→100
recovered only 5 of 31 missing periods, 22 had zero valid pixels wide open. The real leak
is thin cirrus SCL misses, which unmixes as *high albedo* — that fraction anti-correlated
with valid-pixel count at −0.37 to −0.42. Adding s2cloudless CLP ≤ 65%:

    2025-04-H1 clear    0.6% px dropped   high_albedo 0.0241 → 0.0238   (−0.1%)
    2025-06-H1 start    9.5%              0.0485 → 0.0476               (−0.2%)
    2025-05-H1 cloudy   9.0%              0.0907 → 0.0698               (−23%)
    2025-07-H2 cloudy   9.6%              0.1362 → 0.0914               (−33%)

**Gaps are snow, not cloud.** Clear rate by month: 01:35% 02:48% 03:60% 04:68% 05:82%
06:80% 07:85% 08:72% 09:91% 10:100% 11:73% 12:43%. 69% clear overall; of 76 gap runs, 51
are a single fortnight. Interpolation is refused on principle — filling a gap assumes
nothing abrupt happened in it, which is the hypothesis under test.

**Wu & Murray's endmembers are not published as numbers.** They appear only as a plot
(their Fig. 5) and were image-derived from one July-1999 Columbus ETM+ scene. The METHOD
is replicated (N-FINDR on PCs, winsorised, vertex = median of 200 neighbours), not the
values.

**PU cost is identical between APIs** (measured, same AOI/fortnight):

    Process API     PU 0.3289   125,365 bytes
    Statistics API  PU 0.3289     1,402 bytes

CDSE bills pixels processed, not bytes returned. So Statistics is 89× lighter on data but
cannot do per-pixel baselines, connected components, shape or distance. Recommended
architecture: Statistics for a wide cheap screen, Process rasters only for the shortlist.

## 3. The result that stands

Season-matched onset test, 16 site-plan campuses, each site its own control (same
calendar fortnights in earlier years), with a placebo arm (start shifted one whole year):

    metric        REAL mean          95% CI       PLACEBO           verdict
    soil            +0.0814  [+0.0203,+0.1428]     +0.0323          REAL
    vegetation      -0.0548  [-0.0839,-0.0294]     -0.0064          REAL
    ndvi            -0.1476  [-0.2201,-0.0844]     -0.0332          REAL
    ndbi            +0.0383  [+0.0029,+0.0840]     +0.0108          REAL
    swir            +0.0289  [+0.0027,+0.0559]     +0.0140          REAL
    high_albedo     -0.0604       —                -0.0395          placebo fires
    low_albedo      +0.0337       —                +0.0137          placebo fires

Soil up, vegetation down at the reported start, placebo clean. This is a WITHIN-SITE
result: it says something changes at the reported start more than at a fake date a year
earlier. It says nothing about discrimination.

## 4. Mistakes made and corrected — read this before trusting older numbers

1. **Endmember basis drifted between runs.** Each AOI variant extracted its own
   endmembers, so parcel-vs-AOI deltas were measured against different bases. An earlier
   report that a tighter AOI sharpened Digital's high-albedo signal (+0.022 → +0.034) was
   that artefact; on a shared basis it is +0.022 → +0.018, slightly weaker.
2. **Endmembers were mislabelled on sp16.** Labelling by brightness rank put soil (the
   brightest thing on undeveloped land) in the `high_albedo` slot and an ice-like vertex
   in `soil`. Every fraction-level number from that run was reported under the wrong name
   until fixed. Labelling is now by spectral shape with two validity checks.
3. **Slug collision destroyed data.** Three campuses named "Amazon Data Services Inc
   Campus" shared one output directory and overwrote each other's rasters AND grid.json.
   Directories are now uid-suffixed with a hard collision guard.
4. **`pgrep -f` matched its own waiting shell**, deadlocking the downstream chain — the
   exact trap documented in MODEL_STRUCTURE §10.
5. **Reported the fetch complete from a log line** (`done: 1413 calls`) without checking
   the filesystem: 1,236 files in 14 directories, not 1,424 in 16.
6. **Claimed ndbi/swir fail where fractions work.** Held at n=5, did NOT replicate at
   n=16. Withdrawn.

## 5. Data-quality findings for the ACD team

**Digital Dulles contradicts its own label.** Inside its 7 planned building footprints,
high-albedo area never exceeds **0.09 ha** across the entire 2023–2026 record, against an
8,000 m² (0.8 ha) bar. Nothing is ever built on those pads in this imagery, yet the
recorded start is 2025-06-H1. Either the works began elsewhere on the 181 ha campus or
that date is not supported.

**Possible visibility bias in the ground truth.** February is the single largest reported
start month (15.8% of all starts) at 48% clear; Jan–Mar carry 37.9% at 35–60%.
Start-weighted clear rate 66% vs 70% unweighted. If reviewers date a start to when
disturbance BECAME VISIBLE after snowmelt, the truth set is systematically late and no
amount of cloud filtering would show it.

**Site plans mostly postdate their own construction.** Of 27 campuses with both a verified
start and a georeferenced plan, **11 have only sheets dated after the start**. Resolving
as-of each site's own start date across all 229 verified-start sites in the inventory:
206 parcel, 12 site plan, 11 point box.

**`plan-meta.json` has no filing date.** Only `sheet_date`, so `usable_from` falls back to
the document date and every record is flagged "optimistic". Strict leakage protection is
only as strict as the metadata allows. If the intake pipeline starts carrying filing
dates, `usable_from` tightens automatically with no caller changes.

## 6. What is missing

Blocking any performance claim:
1. **Negatives** — zero non-starting campuses fetched at pixel level. No precision, no
   false-alarm rate, no lift is computable. `results/negative_parcels.json` has 150
   identified.
2. **Chronological replay** — the causal detector is tested but never run forward over a
   portfolio. No queue has been produced or scored.
3. **Head-to-head** against the 0.732 AUC baseline on the same sites and split.

Blocking the stage model:
4. **No stage labels exist anywhere.** The 240 records carry a start DATE, not 0/5/10/15.
   Every threshold in `stage.py` is an unfitted guess.
5. **Untested whether 10% and 15% are separable at 10 m.** The abstention path exists
   because the answer is unknown.

Known open defects:
6. Cloud/snow still reaches the endmember pool (1 of 4 vertices on sp16) despite CLP.
7. A 4-endmember model is misspecified for tight site-plan AOIs — no bright impervious
   surface in the pool, so high/low albedo are unanchored there. Pool endmembers over
   wider AOIs, or drop to 3 classes.
8. **SAR never answered** — the principled fix for winter gaps. `sar_stats_cache.json`
   and `sar_resweep.py` exist in acd-polygon-lab; item 5 was killed to prioritise
   negatives on 2026-09-04 and never resumed.

**Cheapest next step that changes what you know:** fetch ~20 non-starting campuses
(~1,800 calls, ~1 h) and re-run the same season-matched test.
